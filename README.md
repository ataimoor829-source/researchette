# Researchette

Research mentorship for students: daily tasks, step-by-step guidance and mentor feedback, from research title to thesis.

## What's here

- `index.html` — the landing page for the medical research mentorship programme (light / dark, liquid-glass style, scroll animations) (single static file, no build step). Open it in a browser or host it on any static host (GitHub Pages, Netlify, Cloudflare Pages).

## Planned

2. **Member portal** — login, daily task with lesson, submission box, mentor feedback, roadmap progress (10 steps, next unlocks on approval).
3. **Admin portal** — see applications and members, create logins, review and approve/return submissions.
